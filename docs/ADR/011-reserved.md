# ADR-011: Reserved

The ADR numbering skips from 010 to 012 because this slot was
reserved but never written. Originally intended for a follow-up
to ADR-010 (anthropic-adapter) that was instead absorbed into
ADR-012 (sdk-integration-status).

If a future round needs to split SDK adapter behavior from
integration status, this slot is the natural place. Until then,
the gap is documented here for traceability.
